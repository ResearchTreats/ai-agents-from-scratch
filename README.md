## Code

Every lesson has two folders:

- `code/lesson-NN/start` — open this folder in VS Code and follow the video: the earlier lessons are complete, this lesson's files are empty.
- `code/lesson-NN/end` — the finished, tested code for that lesson.
- `code/lesson-NN/exercise` — the exercise: make its test pass; `solution` has one answer.

Run the tests in either folder with `python -m pytest -q` (Python 3.10 or newer, with pytest). No API key needed.

# Lesson 07 key terms

- **Ollama** - a program that runs language models on your own machine and answers over a local HTTP address, http://localhost:11434, with no API key
- **tool call** - a structured request in the model's reply, holding a tool's name and its arguments as a JSON object, instead of an 'Action:' line written in text
- **tool definition** - the name, description and JSON Schema of one tool, sent with the request so the model knows which tools it may call

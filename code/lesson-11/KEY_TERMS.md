# Lesson 11 key terms

- **Virtual context** - Main (prompt) + external (searchable) tiers with page in/out
- **Main context** - The prompt — fixed-size, always visible
- **Archival memory** - External searchable persistence, retrieved on demand
- **Core memory** - Named sections pinned inside the main context
- **Memory tool** - Tool call the agent issues to read/write external memory

# EP05 — Build an MCP Server from Scratch in Python (2026 Spec)

▶ **Watch:** https://www.youtube.com/watch?v=0QmrwzPCeaQ

## What you'll learn

- Read and write JSON-RPC 2.0 requests, results and errors
- Implement server/discover, tools/list and tools/call for MCP 2026-07-28
- Reject an unsupported protocol version with the supported list, and still answer a legacy initialize

## Lesson path

1. Build the request/response shapes and version check
2. Implement server/discover, tools/list, and tools/call
3. Serve one JSON message per line
4. Prove the server's behavior with tests

## Commands in this lesson

Run these in the VS Code terminal, in this order.

```
python -c "from mcp_server import result, error; print(result(7, {'tools': []})); print(error(7, -32601, 'Method not found'))"
python -c "from mcp_server import handle; from tools import helpdesk_tools; print(handle({'jsonrpc': '2.0', 'id': 1, 'method': 'initialize'}, helpdesk_tools()))"
python -c "from mcp_server import handle; from tools import helpdesk_tools; r = handle({'jsonrpc': '2.0', 'id': 2, 'method': 'tools/list'}, helpdesk_tools()); print([t['name'] for t in r['result']['tools']])"
'{"jsonrpc": "2.0", "id": 1, "method": "server/discover"}', 'not json' | python mcp_server.py
'{"jsonrpc": "2.0", "id": 3, "method": "tools/list", "params": {"_meta": {"io.modelcontextprotocol/protocolVersion": "1900-01-01"}}}' | python mcp_server.py
python -m pytest -q
```

## Try it yourself

Add a resources capability that lists the help articles, and test that tools/list and your new method both work.

## Check yourself

**Q1. What does error -32022 mean?**

<details><summary>Answer</summary>

Unsupported protocol version: its data lists the versions the server supports, and the one requested.

</details>

**Q2. A notification arrives, with no id. What does the server write back?**

<details><summary>Answer</summary>

Nothing at all: only a request with an id gets a reply.

</details>

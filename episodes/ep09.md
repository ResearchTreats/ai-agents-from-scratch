# EP09 — How to Evaluate AI Agents: Build Evals from Scratch

▶ **Watch:** https://www.youtube.com/watch?v=R1ETAHmbMhQ

## What you'll learn

- Write eval cases that check whether an agent finished, said the right thing, stayed safe and stayed honest
- Run a suite with a fresh shop state for every case
- Gate a release on a pass rate and read which check sank each failing case

## Lesson path

1. Define Case, CASES and make_helpdesk
2. Run the suite and gate the release
3. Prove the eval harness itself works

## Commands in this lesson

Run these in the VS Code terminal, in this order.

```
python -c "from evals import CASES; print(len(CASES))"
python evals.py
python -m pytest -q
```

## Try it yourself

Add a seventh Case for T6 that sets must_not_call to refund, change the gate threshold to 0.5, run python evals.py, and name the checks that come back false and whether the gate passes.

## Check yourself

</details>

**Q2. Why does run_case reset the shop before every case?**

<details><summary>Answer</summary>

So leftover data from one case can't change the next, and every trial starts clean.

</details>

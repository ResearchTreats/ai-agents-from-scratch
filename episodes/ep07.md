# EP07 — Build an AI Agent with Ollama in Python (Local, No API Key)

▶ **Watch:** https://www.youtube.com/watch?v=Mohs1LbdDQU

## What you'll learn

- Call a local model through Ollama's chat API with tool definitions, using plain urllib and no API key
- Translate between the agent's text history and Ollama's tool calls without changing the agent loop
- Run every ticket on a local model and say what it got right, what it got wrong, and which earlier safeguard caught it

## Lesson path

1. Translate history into Ollama's message format
2. Write the brain that calls Ollama
3. Run every ticket on a local model
4. Prove the brain offline with tests

## Commands in this lesson

Run these in the VS Code terminal, in this order.

```
ollama list
python -c "import json; from ollama_brain import to_ollama as t; a='Action: lookup_order ' + json.dumps({'order_id': 'A17'}); h=[{'role':'assistant','content':a},{'role':'tool','content':'Observation: shipped'}]; print(*h, sep='\n'); print(); print(*t(h), sep='\n')"
python -c "from ollama_brain import *; OllamaBrain(helpdesk_tools(), 'qwen2.5:7b').reply([])"
python -c "from ollama_brain import *; print(OllamaBrain(helpdesk_tools()).reply([{'role': 'user', 'content': '[T1] Where is my order A17?'}]))"
python ollama_brain.py
python -m pytest -q
```

## Try it yourself

Pause here and try this: ask the brain for qwen2.5:7b and read the error it gives. Then run python ollama_brain.py on qwen2.5:3b and name the ticket that called no tool, and see what T3 did on your run. Say which earlier safeguard would catch each wrong choice.

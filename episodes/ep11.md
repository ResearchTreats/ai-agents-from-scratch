# EP11 — Give Your AI Agent Memory from Scratch (MemGPT Style)

▶ **Watch:** https://www.youtube.com/watch?v=JsnNdLcQXwY

## What you'll learn

- Explain main context versus archival memory using the RAM and disk analogy
- Page evicted messages into an archive instead of forgetting them
- Recall archived facts by keyword search and keep core facts pinned

## Lesson path

1. Search the archive by keyword overlap
2. Page evicted messages into the archive
3. Prove archive and eviction with pytest

## Commands in this lesson

Run these in the VS Code terminal, in this order.

```
python -c "from memory import Archive; a = Archive(); a.add('Asha prefers a phone call, never email.'); print(a.search('email or phone?'))"
python memory.py
python -m pytest -q
```

## Try it yourself

Build a MainContext with a cap of three and put a customer fact in core. Add a second preference message, then six filler messages. Print the main context and core, then call recall with a query that shares words with that second preference. Confirm the old messages left the prompt, core is unchanged, and recall still finds the fact.

## Check yourself

**Q1. Where does an evicted message go, and which line sends it there?**

<details><summary>Answer</summary>

Into the archive. The add method pops it off the message list, then passes its content to archive add.

</details>

**Q2. Why won't searching for the word telephone find the phone preference?**

<details><summary>Answer</summary>

Search counts shared lowercase words, not meaning. Telephone and phone are different words, so the overlap score is zero.

</details>

# EP10 — Multi-Agent AI in Python: The Supervisor Pattern

▶ **Watch:** https://www.youtube.com/watch?v=urZCbJwWvTA

## What you'll learn

- Explain the supervisor pattern, how it differs from a swarm, and when a supervisor fits
- Route each ticket to a specialist whose ToolBox holds only the tools that team needs
- Escalate to a person instead of guessing when no team matches

## Lesson path

1. Classify tickets into a team or escalate
2. Build scoped specialists and route tickets
3. Prove routing, scoping and escalation with tests

## Commands in this lesson

Run these in the VS Code terminal, in this order.

```
python -c "from supervisor import classify; from tickets import TICKETS; print([classify(t['text']) for t in TICKETS])"
python supervisor.py
python -m pytest -q
```

## Try it yourself

Add a returns team to TEAMS with its own words and tools, and a test that a returns ticket reaches it. Careful: on a tie, the earlier team wins, so pick words no other team uses. Then say in one sentence why a supervisor fits three or four specialists, and when one agent with every tool is enough.

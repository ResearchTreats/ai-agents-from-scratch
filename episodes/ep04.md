# EP04 — AI Agent Function Calling from Scratch in Python

▶ **Watch:** https://www.youtube.com/watch?v=Bp4YL1Uq3uI

## What you'll learn

- Validate a tool call's arguments against its JSON Schema: required, unexpected, type and enum
- Coerce a safe mismatch, like a number sent as a string, and reject the rest
- Run several tool calls from one turn and match each result to its call id

## Lesson path

1. Validate arguments against the tool's schema
2. Coerce safe mismatches and dispatch calls
3. Prove validation, coercion and call ids

## Commands in this lesson

Run these in the VS Code terminal, in this order.

```
python -c "from tools import helpdesk_tools; box = helpdesk_tools(approve=lambda name, args: args['amount'] <= 50); print(box.run('refund', {'order_id': 'B22', 'amount': '25'}))"
python -c "from calling import validate; from tools import helpdesk_tools; print(validate({'order_id': 'B22', 'amount': '25'}, helpdesk_tools().tools['refund'].params))"
python calling.py
python -m pytest -q
```

## Check yourself

**Q1. A model sends amount as the string '12.5'. What does call_all do?**

<details><summary>Answer</summary>

coerce turns it into 12.5, validate finds nothing, and the tool runs.

</details>

**Q2. What if it sends amount as the word 'ten'?**

<details><summary>Answer</summary>

coerce leaves it alone, validate reports 'amount' should be number, got str, and the tool never runs.

</details>

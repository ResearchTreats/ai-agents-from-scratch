# EP06 — Build an MCP Client in Python from Scratch (No SDK)

▶ **Watch:** https://www.youtube.com/watch?v=C8u8LBH6Ir4

## What you'll learn

- Start an MCP server over stdio and exchange one JSON-RPC message per line with it
- Turn a JSON-RPC error reply into an exception and recover from an unsupported protocol version using the supported list the server sends
- Wrap an MCP server's tools so an agent loop calls them like local functions

## Lesson path

1. Send one request to the server
2. Recover from an unsupported version
3. Hand the server's tools to the agent
4. Prove the client with pytest

## Commands in this lesson

Run these in the VS Code terminal, in this order.

```
'{"jsonrpc": "2.0", "id": 1, "method": "server/discover", "params": {"_meta": {"io.modelcontextprotocol/protocolVersion": "1900-01-01"}}}' | python mcp_server.py
python -c "from mcp_client import MCPClient; c = MCPClient(); print(c.request('tools/list')['tools'][0]['name'])"
python -c "from mcp_client import MCPClient; MCPClient(version='1900-01-01').request('server/discover')"
python -c "from mcp_client import MCPClient; c = MCPClient(version='1900-01-01'); print(c.version, c.next_id); c.connect(); print(c.version, c.next_id)"
python mcp_client.py
python -m pytest -q
```

## Try it yourself

Pause here and try this: start a client with an unknown version, connect, list the tools, then call a tool that doesn't exist and print the error code.

## Check yourself

**Q1. Which error code means unsupported protocol version?**

<details><summary>Answer</summary>

Minus 32022, and its data lists the supported versions.

</details>

**Q2. Does the request id act as a session?**

<details><summary>Answer</summary>

No. It only matches one reply to its request.

</details>

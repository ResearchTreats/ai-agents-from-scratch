# EP02 — Give Your AI Agent Tools: Python from Scratch

## What you'll learn

- Explain the describe, decide, execute, observe cycle and say who owns each step
- Define a tool as a name, a JSON Schema for its input and an executor function
- Separate pure tools from side-effecting ones and put the side effects behind an approval check

## Lesson path

1. Write the Tool dataclass and ToolBox
2. Build four real helpdesk tools
3. Wire the toolbox into the agent
4. Prove the approval gate with tests

## Commands in this lesson

Run these in the VS Code terminal, in this order.

```
python -c "from tools import ToolBox; print(ToolBox().run('refund', {}))"
python -c "from tools import helpdesk_tools; print(helpdesk_tools().describe())"
python tools.py
python -m pytest -q
```

## Try it yourself

Add a cancel order tool, mark it as a side effect, and write a test that proves it never runs without approval.

## Check yourself

**Q1. What are the parts of a tool?**

</details>

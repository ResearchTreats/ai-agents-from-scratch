# EP08 — Prompt Injection Attacks on AI Agents: Build a Guard

▶ **Watch:** https://www.youtube.com/watch?v=iNOevlLgpeY

## What you'll learn

- Explain direct and indirect prompt injection with real examples
- Validate every side-effecting tool call against a policy before it executes
- Treat tool output as data by removing instruction-like text from it

## Lesson path

1. Build a phrase filter, then beat it
2. Enforce policy at the tool boundary
3. Prove the guard blocks real attacks

## Check yourself

**Q1. Why can't a phrase filter stop a reworded attack?**

<details><summary>Answer</summary>

It only knows the words on its list, and attackers just rephrase.

</details>

**Q2. Why check each action, not the final answer?**

<details><summary>Answer</summary>

By the final answer, the refund has already run.

</details>

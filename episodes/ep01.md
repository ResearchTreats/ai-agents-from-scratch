# EP01 — Build an AI Agent from Scratch in Python (No API Key)

▶ **Watch:** https://www.youtube.com/watch?v=ZU85eo8BlHk

## What you'll learn

- Explain the observe, think, act loop and the job of its five parts: message list, tools, reply parser, stop condition, and turn budget.
- Build a working agent loop in plain Python that calls a tool and returns a final answer.
- Stop a stuck agent with a turn budget instead of letting it loop forever.

## Lesson path

1. Parse a reply into an action
2. Give the agent a working tool
3. Run the agent loop to completion
4. Prove the agent works with tests

## Commands in this lesson

Run these in the VS Code terminal, in this order.

```
python -c "from agent import parse; from brain import SCRIPTS; print(parse(SCRIPTS['T1'][0]))"
python -c "from agent import lookup_order; print(lookup_order('A17'))"
python -c "from agent import lookup_order; print(lookup_order('Z9'))"
python agent.py
python -m pytest -q
```

## Try it yourself

In the demo at the bottom of agent.py, set the turn budget to three, run it again, and count how many times T5 looks up its order.

## Check yourself

**Q1. What does parse look for before it ever checks for an Action line?**

<details><summary>Answer</summary>

The words Final Answer. If it finds them, it never looks for actions.

</details>

**Q2. What finally stopped ticket T5?**

<details><summary>Answer</summary>

The turn budget. The agent never noticed it was stuck.

</details>
